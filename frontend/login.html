สำหรับผู้ที่สภาเพิ่มสิทธิ์ให้แล้วเท่านั้น
ยังไม่มีสิทธิ์?

  1. 1 หา Discord ID ของคุณ: ใน Discord เปิด การตั้งค่า → ขั้นสูง → โหมดนักพัฒนา แล้วคลิกขวาที่ชื่อของคุณ → คัดลอก ID ผู้ใช้
  2. 2 ส่ง Discord ID พร้อมชื่อตัวละครให้ แอดมิน ประธาน หรือรองประธาน
  3. 3 เมื่อสภาเพิ่ม Discord ID และกำหนดบทบาทให้แล้ว กลับมาที่แท็บ "เข้าสู่ระบบ" แล้วกดเข้าด้วย Discord

ลองเข้าสู่ระบบด้วย Discord หนึ่งครั้ง ระบบจะแสดง Discord ID ของคุณให้คัดลอกส่งให้สภาได้เลย
